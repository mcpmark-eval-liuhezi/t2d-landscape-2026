# Competitive Landscape — Active Type 2 Diabetes Pipeline

This report snapshots the active type 2 diabetes (T2D) pipeline in the ClinicalTrials.gov registry as of today. An aggregate position on the searchable registry's active-study set was defined as overall status **recruiting**, **not yet recruiting**, or **active but not recruiting**. All counts below are quoted exactly as returned by the registry on the day of this pull (no rounding, no estimates), and are as of this pull.

The single largest segment is recruiting (876 of 1,650). The combined "not yet recruiting / active but not recruiting" pool (~774 studies) is where pre-launch and actively-observational activity sits, and it is the segment a grant competitor will be reacting to next.

## Reference Case — SUNSHINE (AstraZeneca, saxagliptin)

The reference case persisted by the PI, NCT01608724 (SUNSHINE), is summarised below from its complete record.

| Field | Registry Record |
| --- | --- |
| NCT ID | NCT01608724 (org study ID D1680L00008) |
| Sponsor | AstraZeneca (Industry) |
| Phase | Phase 4 |
| Study design | Interventional, single-arm, non-randomized, open-label (single group), treatment purpose. 24-week saxagliptin 5 mg once-daily monotherapy in type 2 diabetes patients who were treatment-naive or inadequately controlled on metformin alone. Primary endpoint: absolute change from baseline in HbA1c at weeks 6, 12, and 24. Enrolled 2,165 patients across 92 sites in China. Study completed May 2014; results first posted February 2016. |

SUNSHINE is a post-approval, single-arm Phase 4 program — the registry's own framing, i.e. a real-world-observation-style DTI record rather than a de novo therapeutic trial. As a reference case it documents the DPP-4 inhibitor class posture (saxagliptin/Onglyza) and the arms it was holding against emerging GLP-1 and SGLT2-era competition, which directly contextualises how the class has been displaced in T2D since.
